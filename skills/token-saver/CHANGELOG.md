# What changed

## 1.8.0
The 3 rules now travel to helpers: every brief to a subagent carries them, Claude Code injects them into subagents automatically once the skill is on, and helpers that report their reading show up on the report card instead of being off it.

## 1.7.5
The report card script is now found from the skill's own folder. Agents other than Claude Code no longer search the machine for it or run the wrong copy.
