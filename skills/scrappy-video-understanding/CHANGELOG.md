# What changed

## 1.0.0
First release. Scrappy progressive multi-pass video understanding for any assistant. Built on yt-dlp (Unlicense) and ffmpeg (LGPL/GPL).

## 1.1.0
Starts from the file on disk and never copies it. Never uploads a video anywhere without a yes. Private GitHub release links use the member sign-in; other private links get one plain line. Writes a report.html beside report.md. SKILL.md now lists every output file.

## 1.1.1
A GitHub release download now gets its own folder and title from the file name, so a second private link no longer overwrites the first. Probe and subs stops on a release link exit cleanly, and report.html carries the contact sheet inside it so it reads on a phone without the folder.
